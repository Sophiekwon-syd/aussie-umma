HOW TO FILE
myTax로 직접
신고하는 3단계
1
myGov에 로그인해서 myTax 연결 확인
ato.gov.au 또는 myGov 앱에 접속해요. ATO 서비스가 myGov 계정에 연결돼 있어야 신고가 가능해요.
2
소득 및 공제 항목 입력
고용주 소득은 자동으로 채워져요. 재택근무 시간, 업무 관련 지출 등 직접 입력할 항목만 추가해요.
3
검토 후 제출
예상 환급액 또는 납부액이 표시돼요. 확인 후 제출하면 일반적으로 2주 안에 환급이 들어와요.
